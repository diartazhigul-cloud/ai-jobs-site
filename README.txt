Сайт по проекту «Какие профессии может заменить автоматизация».
Проект по теории вероятностей. Данные: Frey & Osborne (2017) и BLS, файл в папке data.

Как запустить

1. Нужен Python 3.10 или новее.
2. В папке проекта выполнить:
       pip install -r requirements.txt
3. Затем:
       streamlit run app.py
   Если команда streamlit не находится, то так:
       python -m streamlit run app.py
4. Сайт откроется в браузере по адресу http://localhost:8501

Язык сайта

По умолчанию сайт на английском. Переключатель «Language / Язык» стоит в боковом меню слева,
выбор действует сразу на всех трёх страницах и на графиках.

Что где лежит

app.py                 вход, меню из трёх страниц
pages/intro.py         страница «Введение»
pages/analysis.py      страница «Основа», здесь все расчёты и графики
pages/conclusion.py    страница «Заключение»
texts.py               все тексты сайта, английский и русский рядом
i18n.py                переключение языка
calc.py                формулы и статистика (без streamlit)
charts.py              графики
data/                  исходный xlsx-файл
.streamlit/config.toml цвета и шрифт сайта

Все числа на сайте считаются из xlsx при открытии страницы, вручную в тексте их нет.
Если заменить файл в папке data на другой с теми же листами и колонками, сайт пересчитается сам.
